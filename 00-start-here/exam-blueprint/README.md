# Certification mapping (Data Engineer Professional)

## What it is

If you are preparing for the Data Engineer Professional exam, this page maps its sections to folders. The guide dated 9 Oct 2026 has 60 scored multiple-choice questions in 120 minutes, in Python and SQL. Pages tagged with an exam badge (S1 to S9) carry the matching objectives. Questions are scenario-based, so the 'when to choose' and 'traps' blocks matter more than syntax.
